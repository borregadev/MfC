Nested Parentheses Rule

  • Scan left-to-right for the first right parenthesis ')'.
  • Locate the closest left parenthesis '(' directly to its left.
  • Evaluate the inner math expression first.
Evaluating: ((6 + (5 + 3) × 12) / (3 + 5))

Step 1: Inner (5 + 3) = 8 => ((6 + 8 × 12) / (3 + 5))
Step 2: Inner (6 + 8 × 12) => 8 × 12 = 96, 6 + 96 = 102 => (102 / (3 + 5))
Step 3: Inner (3 + 5) = 8 => 102 / 8
Step 4: Final calculation = 12.75

Exponent Rules

  • Base-Index Form: BaseIndex.
  • Zero Power Rule: Any non-zero number to power 0 equals 1 (e.g., 50 = 1).
  • Base 10 Powers: 10n equals 1 with n zeros (e.g., 105 = 100,000).

Propositions & Boolean Variables

  • Proposition: A declarative statement that is strictly True (T / 1) or False (F / 0).
  • Examples: "Paris is the capital of France" (True), "2 + 2 = 5" (False).
  • Not Propositions: Questions ("Is it raining?"), Commands ("Go away!"), or self-referential paradoxes.
  • Boolean Variable: A letter representing a proposition (e.g., p = 'I am in my room').
  • Atomic vs Compound: Atomic propositions are single variables; compound propositions join atomic ones using logic operators.

Negation (NOT: ¬, ~)

Flips the truth value.

  • If p = T, then ¬p = F
  • If p = F, then ¬p = T

Conjunction (AND: ∧)

True only if both operands are True.

  • T ∧ T = T
  • T ∧ F = F, F ∧ T = F, F ∧ F = F

Disjunction (OR: ∨)

True if at least one operand is True.

  • F ∨ F = F
  • T ∨ T = T, T ∨ F = T, F ∨ T = T

Exclusive OR (XOR: ⊕)

True if operands are different (one True, one False).

  • T ⊕ F = T, F ⊕ T = T
  • T ⊕ T = F, F ⊕ F = F

Conditional / Implication (→)

p → q ("If p, then q"). False only if p is True and q is False.

  • T → F = F
  • T → T = T, F → T = T, F → F = T
  • Memory aid: "If you are late (T) and NOT fired (F), the promise was broken (F)".

Bi-conditional / Equivalence (↔)

p ↔ q ("p if and only if q"). True only when both have the same truth value.

  • T ↔ T = T, F ↔ F = T
  • T ↔ F = F, F ↔ T = F

Boolean Operators Order of Precedence

  • 1. Parentheses ( ): Highest precedence.
  • 2. Negation (~ / ¬): Evaluated next.
  • 3. Conjunction (∧): Logical AND.
  • 4. Disjunction (∨): Logical OR.
  • 5. Equal Precedence (⊕, →, ↔): XOR, Conditional, Bi-conditional.
  • Direction Rule: When operators have equal precedence, evaluate from RIGHT to LEFT (opposite to arithmetic math!).

Evaluate: T ∧ T → F

1. AND (∧) has higher precedence than Conditional (→).
2. Compute (T ∧ T) = T.
3. Expression becomes: T → F
4. Compute T → F = F.
Result = F
Evaluate: ~((T ∧ F) → ~T) ∨ F

Step 1: Inner parentheses (T ∧ F) = F => ~((F) → ~T) ∨ F
Step 2: Negation inside parenthesis (~T = F) => ~(F → F) ∨ F
Step 3: Conditional (F → F = T) => ~(T) ∨ F
Step 4: Negation ~(T) = F => F ∨ F
Step 5: Disjunction F ∨ F = F
Result = F
Evaluate: (T ⊕ ((T → F) ∨ ~F)) ↔ T

1. Inner conditional (T → F = F) and negation (~F = T) => (T ⊕ (F ∨ T)) ↔ T
2. Inner disjunction (F ∨ T = T) => (T ⊕ T) ↔ T
3. Inner XOR (T ⊕ T = F) => F ↔ T
4. Final Bi-conditional (F ↔ T = F) => F

Methodology for Building Truth Tables

  • Assign initial columns (1, 2, 3...) to atomic Boolean variables in alphabetical order.
  • Replace variables in the proposition with their column numbers (e.g., r ∧ ~s becomes 1 ∧ ~2).
  • Evaluate operations step-by-step following precedence, placing intermediate sub-expressions in new columns.
  • Once finished, remove intermediate reference columns to leave the final polished truth table.
