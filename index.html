Nested Parentheses Rule

  • Scan left-to-right for the first right parenthesis ')'.
  • Locate the closest left parenthesis '(' directly to its left.
  • Evaluate the inner math expression first.
Evaluating: ((6 + (5 + 3) × 12) / (3 + 5))

Step 1: Inner (5 + 3) = 8 => ((6 + 8 × 12) / (3 + 5))
Step 2: Inner (6 + 8 × 12) => 8 × 12 = 96, 6 + 96 = 102 => (102 / (3 + 5))
Step 3: Inner (3 + 5) = 8 => 102 / 8
Step 4: Final calculation = 12.75

Exponent Rules

  • Base-Index Form: BaseIndex.
  • Zero Power Rule: Any non-zero number to power 0 equals 1 (e.g., 50 = 1).
  • Base 10 Powers: 10n equals 1 with n zeros (e.g., 105 = 100,000).

Base 16 (Hexadecimal) Fundamentals

  • Uses 16 digits: 0–9 and A–F.
  • A₁₆ = 10₁₀ | B₁₆ = 11₁₀ | C₁₆ = 12₁₀
  • D₁₆ = 13₁₀ | E₁₆ = 14₁₀ | F₁₆ = 15₁₀
  • Purpose: Succinctly represents computer memory contents (e.g., F₁₆ represents four binary ones: 1111₂).

Rule: Group bits into sets of 4 from right to left (pad leading zeros on the left if necessary).

Convert 11111011011₂ to Hex:

1. Group in 4s from right: 111 | 1101 | 1011
2. Pad leading 0s on left group: 0111 | 1101 | 1011
3. Convert each group:
   0111₂ = 7₁₆
   1101₂ = D₁₆
   1011₂ = B₁₆
Result = 7DB₁₆

Propositions & Boolean Variables

  • Proposition: A declarative statement that is strictly True (T / 1) or False (F / 0).
  • Examples: "Paris is the capital of France" (True), "2 + 2 = 5" (False).
  • Not Propositions: Questions ("Is it raining?"), Commands ("Go away!"), or self-referential paradoxes.
  • Boolean Variable: A letter representing a proposition (e.g., p = 'I am in my room').
  • Atomic vs Compound: Atomic propositions are single variables; compound propositions join atomic ones using logic operators.

Negation (NOT: ¬, ~)

Flips the truth value.

  • If p = T, then ¬p = F
  • If p = F, then ¬p = T

Conjunction (AND: ∧)

True only if both operands are True.

  • T ∧ T = T
  • T ∧ F = F, F ∧ T = F, F ∧ F = F

Disjunction (OR: ∨)

True if at least one operand is True.

  • F ∨ F = F
  • T ∨ T = T, T ∨ F = T, F ∨ T = T

Exclusive OR (XOR: ⊕)

True if operands are different (one True, one False).

  • T ⊕ F = T, F ⊕ T = T
  • T ⊕ T = F, F ⊕ F = F

Conditional / Implication (→)

p → q ("If p, then q"). False only if p is True and q is False.

  • T → F = F
  • T → T = T, F → T = T, F → F = T
  • Memory aid: "If you are late (T) and NOT fired (F), the promise was broken (F)".

Bi-conditional / Equivalence (↔)

p ↔ q ("p if and only if q"). True only when both have the same truth value.

  • T ↔ T = T, F ↔ F = T
  • T ↔ F = F, F ↔ T = F
